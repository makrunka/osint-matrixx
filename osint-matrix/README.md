# OSINT-Matrix

Система підтримки прийняття рішень для вибору ШІ-інструментів в
OSINT-розслідуваннях. Детермінована матриця маршрутизації (Розділ 2.3
наукової роботи) доповнена чат-асистентом на базі Claude API, який лише
класифікує задачу аналітика природною мовою — не вигадує інструменти чи
оцінки поза базою правил.

## Локальний запуск

1. Встанови залежності:
   ```
   pip install -r requirements.txt
   ```

2. Створи файл `.streamlit/secrets.toml` (він вже в `.gitignore` — ніколи
   не потрапить у репозиторій) і додай туди свій ключ:
   ```
   ANTHROPIC_API_KEY = "sk-ant-..."
   ```

3. Запусти:
   ```
   streamlit run app.py
   ```

## Деплой на Streamlit Community Cloud

1. Заливаєш цей репозиторій на GitHub — файл `secrets.toml` НЕ потрапить
   туди завдяки `.gitignore`.
2. На share.streamlit.io підключаєш репозиторій, вказуєш `app.py` як
   головний файл.
3. У налаштуваннях застосунку (⚙ Settings → Secrets) вставляєш той самий
   рядок `ANTHROPIC_API_KEY = "sk-ant-..."` — саме тут, а не в коді.

## Важливо

Ніколи не вставляй реальний API-ключ безпосередньо в `app.py` чи в будь-який
файл, що потрапляє в git. Ключ живе тільки в `secrets.toml` (локально) або в
розділі Secrets налаштувань Streamlit Cloud (після деплою).
